# 税海拾珠 · 项目方向

TaxPearls 面向企业财务、代理记账机构与财税教学，提供可解释的税务风险核对能力。企业端依据上传材料排查账税差异、财务异常与涉税风险线索，并说明材料缺失造成的检查盲区。每项结论应包含原始数值、取数来源、计算过程、阈值、依据和建议，供使用者复核。

## 产品场景

| 场景 | 目标 |
| --- | --- |
| 企业财务自用 | 核对本企业材料，确认检测范围，复核线索并保存报告 |
| 代理记账机构 | 管理多家客户；每次检测一家企业、一个主期间 |
| 财税教学 | 使用仿真材料开展查账、风险标注、证据复核与评分 |

使用机构与被检测企业是两个层级。材料按机构权限隔离、按被检测企业归集，相同税号不能跨机构打通数据。企业自用能力与收费、获客渠道分别讨论。

## 企业业务流程

目标流程为直接上传 → 核对企业、税号与主期间 → 分析归属和输入范围 → 用户确认材料快照 → 执行适用规则 → 复核结果并导出报告。一次检测可含多份文件，同企业的历史参考保留实际期间和用途，不混入本期金额。

用户可补填或修改字段；原文值、用户值和派生值分别保留。明确的主体或期间冲突仍须处理，用户指定归属不能充当原件证明。分析阶段只检查输入与可计算性，不提前作出风险结论。反馈分为必须处理、缺失但可继续、建议补充。

## 当前范围与后续能力

Web 工作台支持真实登录、多源材料解析、24 条条件规则、关联方图分析、证据与报告、跨期比较和冻结归档。账号、通知、教学及运行工具的具体进度见 [README](../README.md)。

企业输入分析、标准数值修正与提取溯源核心已实现，公开接口和页面接入仍待完成。原件受控留存、持久化确认快照、补传重检、原件访问与删除日志属于后续交付；目标需求不代表已完成验收。

## 技术与使用边界

- 识别层采用确定性规则，保留证据和计算口径；材料不足保持未执行。
- 报告说明问题、依据、核查建议、已完成检查及判断限制；发现差异不等于认定违法，检测完成不等于风险已整改。
- 模型只辅助提取、解读和问答，不补造材料，不改写确定性结论；未知模型版本不虚构。
- 原件应保存上传字节和指纹，转换结果另存，并接受权限、加密、备份和访问日志保护；具体接入仍按待办验证。
- 开发与教学演示使用仿真材料；真实客户账套不得作为教具。真实业务接入须分别验证材料适配、权限、安全和运行环境。
