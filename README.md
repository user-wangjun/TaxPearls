AI 税务审计 SaaS 平台。

## prototype/ 原型说明

单文件 HTML，Tailwind CDN + Chart.js CDN，双击浏览器直接打开。

**已实现（可点击演示）**

| 模块 | 状态 |
| --- | --- |
| 登录 → 5 角色切换（企业 / 税务机关 / 教师 / 学生 / 管理员） | ✅ 菜单与页面渲染正常 |
| 审计报告列表 → 详情跳转 | ✅ |
| 风险评分可视化 | ✅ Chart.js 渲染（数据为随机数） |
| 文件上传控件 | ⚠️ 仅读取文件名与大小，内容未进入程序 |
| 智能问答 | ⚠️ 关键词匹配本地政策文本，**非模型调用** |

**已知空壳（点击无响应或假动作）**

- `renderGrading` — 硬编码「暂无待批改的作业」
- `renderBatch` — 「选择文件」按钮未绑定事件
- `renderRules` — 「保存配置」未绑定事件
- `renderUsers` / `renderPolicies` — 编辑、删除按钮均为空
- `downloadReport` — 仅 `alert`，未生成文件
- 登录 — 密码硬编码 `123456`，角色由下拉框直接决定，无鉴权

**已知缺陷（落地前必须解决）**

1. **数据不持久** — `mockData` 存于内存，刷新即清零。
2. **XSS 无防护** — 全部通过 `innerHTML` 拼接用户输入，未做转义。
3. **AI 名不副实** — 无任何模型调用，风险评分为 `Math.random()` 生成。
4. **核心链路缺失** — 「从发票 / 银行流水中读出税务问题」这一关键能力完全未实现。
