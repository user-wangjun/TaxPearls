# 08 - 考证刷题线使用说明（教师端 / 学生端）

> 适用版本：main 分支（2026-10 交付基线）。目标用户：高校教师（管理员）与学生。
> 部署与备份见 05 号文档；需求背景见 07 号文档（TP-CERT-001）。

## 一、启动系统

1. 双击 `instance\启动教师系统.bat`（黑窗口即服务器，**保持开着**，关闭 = 停止服务）。
2. 教师页：`http://127.0.0.1:8000/training-staff`
3. 学生页：`http://127.0.0.1:8000/training-certificates`
4. 首个教师账号由部署时创建（初始示例：staff01）。**首次登录后请立即点右上角「改密码」**。

## 二、教师端操作指南（training-staff）

登录后自上而下依次是：

### 1. 证书与考试日期
- 「＋ 新建证书」：编码（如 cjkj）、名称、科目清单（逗号分隔）。
- 「考试日期 → ＋ 录入日期」：类型选「官方考试日」（有官方公告时）或「预计考试日」；学生倒计时**官方日期优先**，没有官方日期时用学生个人计划日兜底。日期被学生目标引用时删除会被拒绝。

### 2. 内容版本（题源治理）
- 同一证书仅一个启用版本；发布新版本自动退役旧版本；旧作答仍按当时版本回溯。
- 题源两类：**规则仿真题**（系统生成、明确标注非真题，发布无需授权）与**真题 / 回忆题 / 模拟题**（外部题源，发布前须先登记覆盖该题源的生效书面授权）。
- 外部题源发布时，授权文号自动写入版本「依据」留痕；无授权或授权已过期/撤销会被拒绝（422，提示补授权）。

### 2.1 题源授权登记（决策三：授权先行、不自行采集）
1. 与命题管理方或其授权出版方取得**书面授权**后，在「题源授权登记」卡片填写：授权方、授权文号、生效日、失效日（留空 = 长期）、覆盖题源（真题 / 回忆题 / 模拟题可多选）、使用范围说明。
2. 保存后列表显示状态：**生效中**（当日可用）/ **未生效或已过期**（不能用于发布与导入）/ **已撤销**。
3. 授权可提前登记未来生效日（如 12 月签、次年 1 月生效），到期前不影响现状；到期后自动不可用。
4. 「撤销」只改状态、**不删除记录**，可审计；撤销后已发布版本与存量作答不受影响，但不能再发布新版本、不能再导入题库、存量草稿不能再提交审核。
5. 同一证书内授权文号唯一（重复登记会被拒绝）。

### 2.2 题库导入与审核
- **导入**：粘贴人工核对过的 JSON 数组，每题字段 `source_type`（real/recall/mock）、`year`、`stem`、`options[{key,text}]`、`answer_keys`、`explanation`，可选 `question_no`、`knowledge_point_id`。**不解析 PDF / Word**，不接受未核对的抓取内容。
- **逐行校验**：合法行入库为「草稿」，非法行（缺解析、答案键未定义、题源不支持、非 JSON 对象）**逐行返回原因且不中断整批**，结果区按行列出成功/失败。
- **审核流转**：草稿/被驳回 →「提交审核」（提交时复查授权仍生效）→「待审」→「通过」（上线，学生才抽得到）或「驳回」（填审核意见，可改后重新提交）。
- **下架**：已上线题可下架回草稿，学生不再抽到；**历史作答仍按当时题干与解析回看**，不受下架影响。
- 答案与解析在学生**提交判分后**才开放，作答中不下发。

### 3. 考纲知识点
- 树状结构（编码/名称/科目/上级）。「⇪ 批量导入」支持清单 Markdown 或 CSV，按编码幂等导入（已存在只更新非空字段）。
- 每个知识点卡片下有三个入口：
  - **＋ 规则**：挂接风险规则（学生刷题的题目来源）；
  - **＋ 标注**：三类标注（考证高频 / 企业风险 / 学生易错），「考证高频」必填依据与依据版本；
  - **＋ 关系**：前置知识 / 概念关联 / 易混淆（用于图谱与学习路径）。
- 「内容运营统计」卡片按证书 × 依据版本汇总标注与题目关联覆盖情况。

### 4. 学生管理（本交付新增）
- **＋ 添加学生**：院校（必填）、学号、姓名、班级选填；初始密码留空 = `Tp#学号2026`。
- **⇪ 批量导入（文本）**：粘贴名单，每行 `学号,姓名,班级`（逗号或中文逗号，空行忽略），设置统一初始密码（≥8 位）与默认班级。
- **⇪ 批量导入（Excel）**：直接上传 `.xlsx` 名册——第一行须为表头且含「学号」「姓名」列（「班级」可选，表头写「学生学号/学生姓名/行政班级」也可识别）；公式单元格只读缓存值、不执行公式，公式无缓存按空值处理；空行忽略；文件 2MB / 1000 行上限整体拒绝。
- **重复与错误行**：两种导入方式都会逐行说明原因（如学号已存在），不部分静默成功。
- **重置密码**：立即清除该学生全部登录会话（踢下线），把新密码线下告知学生。
- **停用/启用**：停用立即拒绝登录；启用即恢复。学生记录不物理删除（作答历史与档案保留）。
- 学生登录入口在学生页，用「学号 + 密码」（多院校存在同学号时需再填院校名）。

### 5. 班级、组织架构与席位配额（本交付新增）
- **班级名册卡**：按学生名册「班级」字段聚合统计在读人数；「整建制迁移」把一个班的在读学生整体转到新班级（逐生留痕，可追溯操作人与时间）；教师账号批量导入（登录名,姓名,邮箱）仅限管理员。
- **组织架构卡**（院系 / 学年学期 / 班级实体，写操作仅限管理员）：
  - **院系**：如「会计学院」；被班级引用的院系不能删除，可归档保留；
  - **学年学期**：如「2026-2027-1」，可设「当前学期」（同校唯一）；**生成名册快照**把当前在读学生的班级归属冻结到该学期，新学期重建班级后仍可「查看快照」回溯旧名册；重拍覆盖更新；
  - **班级实体**：与上方学生名册**并存**——学生「班级」字段照常使用，班级实体按名称对齐在读人数；支持「按学期重建」（复制到新学期，学生不动，归属调整仍用整建制迁移）。
- **席位与配额**：教师/学生分席核销——创建即占用、停用即腾出；未配置院校按默认档（教师 10 / 学生 200）放行；导入遇席位满会逐行说明原因、不中断整批；管理员可在卡片内调整配额（每次调整留痕，记录新旧值与操作人）。

### 6. 密码与账号安全
- 头部「改密码」：验证当前密码，新密码 ≥8 位且不得与旧密码相同；成功后**所有会话失效**（含当前页），需重新登录。
- 忘记密码：由其他管理员重置；单管理员部署时需在库内重置（见 05 号文档）。

### 7. AI 备课助手（把教学想法变成学生任务，2026-10-21 新增）
入口：顶部导航「实训中心」→ 面板最上方「AI 备课助手：把教学想法变成学生任务」。

1. **写想法**：把这一节课要讲的内容贴进「教学想法 / 备课材料」（至少 20 字），也可以点「载入本地文档」选一个 `.md` / `.txt`（≤200KB，会追加到文本框）。**不解析 PDF / Word**，需要时先自己粘成纯文本。
2. **选题量与题型**：默认 5 题、单选；可选「单选 + 多选」或「多选」。题量 3–20。
3. **生成草稿**：点「生成草稿」，模型会拆出 3–8 条知识点和指定数量的客观题（每题含选项、答案、解析、材料原句）。**AI 只产出草稿，学生看不到**。
4. **逐题核对（必须做）**：草稿区可以直接改标题、知识点名称/要点/难度、题干、选项文字、解析；勾选框决定正确答案（单选只能勾一个，多选至少两个）；「删除这道题」「删除这条知识点」可裁掉不合格内容。
5. **保存 / 发布**：点「保存草稿」留着自己再看；点「发布给学生」后，所选范围的学生在「实训中心 → 老师布置的学习任务」里就能看到并能作答。
6. **范围与统计**：「发布到班级」默认「全机构学生」，也可只发给某个教学班级（班级在「师生与班级」里建）。任务列表显示「已提交 x/y 人 · 平均 n 分」。
7. **改与撤**：草稿可继续编辑或删除；**已发布任务不能再改题目**（避免学生已作答的答案被换掉），需要调整就归档后新建。归档后学生不再看到，已提交记录保留。

纪律与边界：
- 模型未配置 / 调用失败 / 输出不合规（答案不在选项内、题型不符）时**直接报错，不落库、不补造题目**；此时可稍后重试或改为人工录入。
- AI 生成的知识点**只随这份任务下发**，不写入证书考纲知识点库（`knowledge_point`），不会污染 113 条已核验考纲知识点。
- 判分口径：总分 100，按题数均分；**多选须完全匹配**（漏选、错选都不得分）。答案与解析在学生**提交后**才开放，作答中不下发。
- 每位学生对同一任务**只能提交一次**，避免反复刷分。

## 三、学生端操作指南（training-certificates）

1. **登录**：学号 + 密码（初始密码由教师发放；首次登录后请点右上角「修改密码」自助改为私密密码）。
2. **选证书、设目标**：在证书目录选择「初级会计职称」，设定考试日期（可选官方日期或个人计划日）。首页即显示**倒计时**（按中国日历日，永不为负）。
3. **自主练习**：选择题源（规则仿真题 / 真题 / 回忆题 / 模拟题，后三者须教师已登记授权并审核上线）→ 选知识点（不选则整证随机）→ 作答 → 提交判分 → **解析在判分后开放**。仿真题按确定性种子出题（可重做同题）；题库题按题号抽题，判分为选项集合完全匹配（多选漏选/错选均不得分）。
3.1 **老师布置的学习任务**（2026-10-21 新增）：「实训中心」面板最上方是「老师布置的学习任务」。点「开始作答」会展开老师下发的知识点和题目（单选/点选、多选勾选），答完点「提交作答」即判分并显示每题对错、正确答案与解析。**每题作答前不下发答案**；同一任务只能提交一次，提交后再点开是「查看结果与解析」。
4. **错题重练**：错题本支持「原题重做（同种子）」或「再练新题」；覆盖统计显示知识点的练习覆盖与掌握程度。
5. **笔记与提问**：每个知识点可写个人笔记（可删除）；有疑问可发起 AI 答疑——AI 只解释思路，**不改判分数、不代替教师维护内容**。
6. **学习档案**：按知识点聚合个人作答、错题、笔记与提问记录；掌握程度四级口径，一次重练答对不代表长期掌握。
7. **修改密码 / 退出登录**：右上角「修改密码」验证当前密码，新密码 ≥8 位且不得与旧密码相同，成功后**所有会话失效**需重新登录；「退出登录」立即失效当前会话。

## 四、边界与合规要点（务必知悉）

- 知识点内容依据 **2026 年度全国会计考办大纲**人工整理；机构资料与 AI 生成考纲不作依据。
- 题目分两类：**规则仿真题**由系统生成、页面明确标识，不冒充真题；**真题 / 回忆题 / 模拟题**为外部题源，须先取得书面授权（授权文号写入版本与题目的 source_ref 留痕）并经审核上线，软件侧不采集、不爬取、不代理授权谈判。
- **截至 2026-10-20 未取得任何真题书面授权**：授权登记与题库导入通道已就绪并本地验证，但真实真题内容须待 2026 年 12 月授权落地后由管理员登记导入。
- AI 答疑不改判、不代写内容；个人易错数据仅本人可见，不反向写入公共标注。
- 2027 年官方考务公告发布后（预计 2026 年 12 月上中旬），教师应在「考试日期」录入官方日期；2027 版大纲发布后升内容版本。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 登录提示「用户名或密码不正确」 | 确认服务用 bat 启动（连主库）；检查大小写/全角符号；密码遗忘走重置 |
| 浏览器 Failed to fetch | 服务未启动或黑窗口被关；重新双击 bat |
| 批量导入某行被跳过 | 看结果明细：多为重复学号或格式缺姓名 |
| 学生说「突然被退出」 | 教师重置过密码或停用账号，与学生确认 |
| 倒计时显示过期 | 官方日期已过仅作标记，不会自动改学生目标状态 |
