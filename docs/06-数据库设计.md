## 一、设计约定

沿用现有系统的存储约定（参照 `webapp/classroom.py`、`webapp/storage.py` 现行实现）：

1. **主键**：统一使用 `id TEXT PRIMARY KEY`，由应用层生成 UUID 字符串；
2. **机构隔离**：业务表均带 `org_id TEXT NOT NULL`，读写路径复查归属（与现有"读取与写入均复查归属"模式一致）；
3. **时间字段**：统一 `TEXT`，存 ISO-8601 字符串（与 `training_papers.created_at` 现状一致）；
4. **布尔值**：统一 `INTEGER`（0/1）；
5. **外键**：声明 `REFERENCES xxx(id)`，删除策略在业务层控制，不启用级联删除；
6. **敏感字段加密**：手机号、邮箱、代码提交正文等按 05 号文档要求走字段级 AES-256-GCM 加密存储，密文仍存 `TEXT` 列。

## 二、表关系总览

```
users(现有账号表)
  │
  ├──< university_admins     高校管理员（1 账号 : 1 管理员档案）
  │
users(教师) ──< training_tasks >── training_classes(现有班级表)
  │                                   │
  └──< training_submissions ──────────┘
            │
            └──< training_scores（1 提交 : 1 评分结果，可含教师调分版本）
```

## 三、表结构

### 3.1 管理员表 `university_admins`

高校管理端管理员档案，与现有 `users` 账号表一一关联，表达校级/院系两级管理视角（差距 A 的组织结构缺口）。

| 字段            | 类型      | 主键 | 说明                                       |
| ------------- | ------- | -- | ---------------------------------------- |
| id            | TEXT    | 是  | 主键，UUID                                  |
| org_id        | TEXT    |    | 所属院校机构 ID，关联现有机构，NOT NULL，机构隔离依据          |
| user_id       | TEXT    |    | 关联账号 ID（`users.id`），UNIQUE NOT NULL，一人一档案 |
| username      | TEXT    |    | 登录名，机构内 UNIQUE NOT NULL                  |
| display_name  | TEXT    |    | 姓名，NOT NULL                              |
| admin_level   | TEXT    |    | 管理层级：`school`（校级）/ `department`（院系级），NOT NULL |
| department_id | TEXT    |    | 院系 ID；`admin_level = school` 时为空，院系级管理员 NOT NULL |
| email         | TEXT    |    | 邮箱（加密存储），用于通知与找回                         |
| phone         | TEXT    |    | 手机号（加密存储）                                |
| status        | INTEGER |    | 状态：1 启用 / 0 停用，默认 1                      |
| created_at    | TEXT    |    | 创建时间，ISO-8601，NOT NULL                   |
| updated_at    | TEXT    |    | 最近更新时间，NOT NULL                          |

### 3.2 实训任务表 `training_tasks`

教师/管理员发布的实训任务。代码实训沿用现有班级作业框架（`training_classes`、`training_papers`），本表承载任务本身与判题配置。

| 字段             | 类型      | 主键 | 说明                                              |
| -------------- | ------- | -- | ----------------------------------------------- |
| id             | TEXT    | 是  | 主键，UUID                                         |
| org_id         | TEXT    |    | 所属院校机构 ID，NOT NULL，机构隔离依据                        |
| task_no        | TEXT    |    | 任务编号，如 `TASK-2026-0001`，机构内 UNIQUE NOT NULL      |
| title          | TEXT    |    | 任务标题，NOT NULL                                   |
| description    | TEXT    |    | 任务说明（Markdown 文本）                               |
| task_type      | TEXT    |    | 任务类型：`code`（代码实训）/ `report`（报表实训）/ `rule`（规则实训），NOT NULL |
| language       | TEXT    |    | 技术栈/语言标识（如 `python`、`sql`）；非代码任务存科目标识            |
| class_id       | TEXT    |    | 面向班级 ID，关联 `training_classes(id)`，NOT NULL        |
| creator_id     | TEXT    |    | 创建人 ID（教师或管理员，`users.id`），NOT NULL               |
| difficulty     | INTEGER |    | 难度 1–5，默认 3                                     |
| total_points   | REAL    |    | 总分值，CHECK（total_points > 0），默认 100               |
| starter_code   | TEXT    |    | 起始代码/模板（可空）                                     |
| judge_config   | TEXT    |    | 判题配置 JSON（用例清单、时限、比对口径）；`task_type = code` 时 NOT NULL |
| published      | INTEGER |    | 发布状态：1 已发布 / 0 草稿，默认 0                          |
| deadline_at    | TEXT    |    | 截止时间，ISO-8601                                   |
| revision       | INTEGER |    | 版本号，默认 1，每次发布后自增（沿用现有 revision 口径）               |
| created_at     | TEXT    |    | 创建时间，NOT NULL                                   |
| updated_at     | TEXT    |    | 最近更新时间，NOT NULL                                 |

### 3.3 学生提交记录表 `training_submissions`

学生针对任务提交的作业记录，支持多次尝试，保留全部历史（评分事实来源，对应差距 B 的提交物变化）。

| 字段            | 类型      | 主键 | 说明                                              |
| ------------- | ------- | -- | ----------------------------------------------- |
| id            | TEXT    | 是  | 主键，UUID                                         |
| org_id        | TEXT    |    | 所属院校机构 ID，NOT NULL（冗余自任务，隔离复查用）                  |
| task_id       | TEXT    |    | 任务 ID，关联 `training_tasks(id)`，NOT NULL           |
| student_id    | TEXT    |    | 学生账号 ID（`users.id`），NOT NULL                    |
| attempt_no    | INTEGER |    | 第几次提交，同一（task_id, student_id）内自增，默认 1，NOT NULL    |
| code_content  | TEXT    |    | 提交正文：代码文本或报表数据快照（大文本；代码实训按 05 号文档要求加密留存）        |
| file_name     | TEXT    |    | 提交附件原始文件名（可空）                                   |
| file_hash     | TEXT    |    | 提交内容 SHA-256 摘要，用于防篡改与查重比对                      |
| status        | TEXT    |    | 状态：`submitted` 已提交 / `judging` 判题中 / `graded` 已评分 / `failed` 判题失败，NOT NULL |
| is_late       | INTEGER |    | 是否迟交：1 是 / 0 否，按 `deadline_at` 判定，默认 0          |
| submitted_at  | TEXT    |    | 提交时间，ISO-8601，NOT NULL                          |
| created_at    | TEXT    |    | 记录创建时间，NOT NULL                                 |

约束：`UNIQUE(task_id, student_id, attempt_no)`。

### 3.4 评分结果表 `training_scores`

判题引擎与教师批改的评分结果，回填现有评分框架（自动评分事实 + 教师调分留痕，口径与 `src/training.py` 一致）。

| 字段             | 类型      | 主键 | 说明                                                     |
| -------------- | ------- | -- | ------------------------------------------------------ |
| id             | TEXT    | 是  | 主键，UUID                                                |
| org_id         | TEXT    |    | 所属院校机构 ID，NOT NULL（冗余自任务，隔离复查用）                         |
| submission_id  | TEXT    |    | 提交记录 ID，关联 `training_submissions(id)`，NOT NULL           |
| task_id        | TEXT    |    | 任务 ID，关联 `training_tasks(id)`，NOT NULL（统计冗余列）           |
| auto_score     | REAL    |    | 判题引擎自动评分，可空（判题失败时无值）                                   |
| teacher_score  | REAL    |    | 教师调分/批改分数，可空；仅教师角色可写                                   |
| final_score    | REAL    |    | 最终成绩：有 `teacher_score` 取教师分，否则取 `auto_score`，应用层计算       |
| passed_cases   | INTEGER |    | 判题通过用例数，默认 0                                          |
| total_cases    | INTEGER |    | 判题用例总数，默认 0                                           |
| hit_count      | INTEGER |    | 命中风险点数（规则类实训沿用现有命中口径）                                  |
| missed_count   | INTEGER |    | 漏检风险点数（同上）                                             |
| false_alarm_count | INTEGER | | 误报风险点数（同上）                                             |
| score_detail   | TEXT    |    | 评分明细 JSON（逐用例/逐风险点结果），供评分明细页展示                          |
| teacher_comment| TEXT    |    | 教师评语                                                   |
| score_source   | TEXT    |    | 最终分来源：`auto` / `teacher` / `mixed`，NOT NULL             |
| grader_id      | TEXT    |    | 评分人：判题引擎标识或教师账号 ID，NOT NULL                            |
| graded_at      | TEXT    |    | 评分时间，ISO-8601，NOT NULL                                 |
| created_at     | TEXT    |    | 记录创建时间，NOT NULL                                        |
| updated_at     | TEXT    |    | 最近更新时间，NOT NULL                                        |

约束：同一提交允许多条评分记录（自动评分 + 教师调分各一条），以 `graded_at` 最新且 `score_source = teacher` 者为教师终版；查询最终成绩时按应用层规则取 `final_score`。

## 四、索引与隔离要点

| 表                     | 建议索引                                                         | 用途             |
| --------------------- | ------------------------------------------------------------ | -------------- |
| university_admins     | `UNIQUE(org_id, user_id)`、`INDEX(org_id, admin_level, department_id)` | 一人一档案、按层级查管理员  |
| training_tasks        | `UNIQUE(org_id, task_no)`、`INDEX(org_id, class_id, published)` | 编号唯一、按班级列任务    |
| training_submissions  | `UNIQUE(task_id, student_id, attempt_no)`、`INDEX(task_id, status)` | 防重复提交、判题队列扫描   |
| training_scores       | `INDEX(submission_id)`、`INDEX(task_id, student_id)`           | 单提交取分、学情统计     |

所有业务读写路径延续现有"归属复查"模式：以会话账号所属 `org_id` 过滤，跨机构 ID 一律拒绝；教师调分写入前复查其对该任务所属班级的权限。备份与恢复按 05 号文档既有认证加密备份机制执行，新表纳入同一备份范围。
