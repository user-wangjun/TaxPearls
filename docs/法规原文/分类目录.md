# 法规原文分类目录

本批围绕现有24条规则引用的五部法律及直接配套规定收集，并补充企业所得税基础原文。保存官方页面原始字节、可检索文字及页面直接链接的附件。这里是资料交付，不是已发布知识库，也没有改动业务 schema。

共 26 份官方页面快照（其中一份为已有征管法引用页，另有同法主来源），8 份官方附件；分类为三个税种和三类支撑依据。检索文字、条号定位、来源和 SHA-256 见 [来源清单](来源清单.json)。各文件实际抓取时间分别记录在清单内（Asia/Shanghai）。

## 图谱迁移范围

`src/policy_migration.py` 在八类图谱 Schema 中迁入本目录的 25 份政策及 1,289 个原有条款/章节节点，并合并 `国家级税费政策.yaml` 的五个主题、`广东省地方政策.yaml` 的两个主题。12 份目录来源文字快照与原有官方原件分别保留来源、哈希和版本；同 URL 的快照不冒充同一份原件。目录解释和官方原文也分别标记来源类型。

迁移保留主体概念候选、原文条件、例外、政策参数、所需业务字段、条款推导关系和分主体施行时间。全部原文片段均有覆盖记录及字符位置；章、节等结构节点单独标记。原有 24 条筛查规则与 VAT-R01 保持原执行逻辑和历史记录。

迁移结果是待审核知识。文字条件保留为 `PolicyInterpretation`，主体匹配为待复核候选；没有把句子中的“或”“除外”等未经解释的逻辑自动编译为 AND，也没有把禁令一律当作免税排除。此类条件不能通过现有自动执行映射校验。目录参数及取数要求迁入字典，既有七个主题的条件判断仍由 `src/policies.py` 实现，不新增税款计算。政策效力、解释和适用性审核不因迁移自动通过。

显式本地迁移入口为 `python scripts/migrate_policy_knowledge.py --db <数据库路径> --report <验收报告路径>`；现有库在写入前自动做 SQLite 一致性备份。重复导入保持稳定 ID，保留已复核字段与已留存的原件位置，失败时回滚本次数据和新建留存文件。管理员的原文导入接口也使用同一迁移计划。

## 分类原则

| 分类 | 性质 | 说明 |
| --- | --- | --- |
| 增值税 | 税种 | 法律、实施条例、范围注释、优惠衔接和历史条例 |
| 个人所得税 | 税种 | 法律、修正决定、实施条例、扣缴规定 |
| 企业所得税 | 税种 | 法律和2024年修订实施条例；基础储备 |
| 征管通用 | 跨税种支撑 | 征管法、细则、发票办法、电子发票制度；发票不是税种 |
| 会计规范 | 非税种支撑 | 会计法和会计准则；所得税会计不等于企业所得税征税规则 |
| 社保依据 | 非税种支撑 | 社会保险法；社会保险费不归入个人所得税 |

保留原规则的 `tax_type` 标签。原来的“综合”在资料分类中归为会计核对，不另造“综合税”。文件同时保存 `tax_types`、`domain`、`legal_level`，多税种或跨税种文件可独立标注；按文件主归属保存一次，不为每条规则复制法规。
