# 税海拾珠 · 运行、备份与恢复

## 本机运行

使用 `python -m webapp --host 127.0.0.1 --port 8000` 启动，`/healthz` 用于存活检查。数据库由 `TAXPEARLS_DB` 指定，默认写入 `instance/taxpearls.db`。配置文件使用 `.env`，填写前从无密钥的 `.env.example` 复制。

Windows 使用本机 Chrome 导出 PDF；Linux 容器配置 `TAXPEARLS_PDF_BROWSER=chromium`。固定依赖见 `requirements.lock`。企业材料原件、分析和确认版本已持久化；兼容教学草稿仍在进程内存中。本机分析并发控制按单进程执行，多副本部署须另行验证。

本机、CI 与正式运行使用各自独立的数据库和配置。统一检查入口自动使用临时数据库并关闭外部模型和邮件发送，不使用业务库执行回归；CI 的只读仓库权限和测试通过不等于正式部署已完成。

## 备份、验证与恢复

使用 SQLite 在线备份 API 在内存中捕获已提交的 WAL 数据，再用 AES-256-GCM 认证加密生成 `.tpbackup` 文件；不生成中间明文备份。密钥 `TAXPEARLS_BACKUP_KEY` 必须是独立的 32 字节随机密钥的 Base64，并通过安全方式注入进程环境。运维脚本不自动加载 `.env`，也不接受命令行密钥；请将密钥与备份分开保管。

```powershell
python scripts/ops_db.py backup-encrypted --database instance/taxpearls.db --output backups/checkpoint.tpbackup --retention-days 30
python scripts/ops_db.py verify-encrypted backups/checkpoint.tpbackup
```

示例的 30 天仅是参数示范，实际保留期由业务与运维要求决定。校验会检查密钥、认证标签和数据库完整性，密钥错误或内容被修改时拒绝恢复。已有输出文件不会覆盖。

恢复会替换指定数据库。先停止应用服务，再执行；脚本检测 SQLite 日志和运维锁，先生成并验证现有数据库的加密安全副本，随后恢复。恢复期间若目标数据库发生变化则取消覆盖。

```powershell
python scripts/ops_db.py restore-encrypted backups/checkpoint.tpbackup --database instance/taxpearls.db --safety-retention-days 30 --yes
```

恢复返回安全副本位置；需要回退时仍须停服，以该 `.tpbackup` 副本为恢复输入。密钥、数据库、备份和回执均不纳入 Git。明文兼容命令 `backup` 和 `restore` 仅供迁移或测试，必须明确提供 `--allow-plaintext`；明文恢复还需 `--yes`。

## 保留期与销毁回执

```powershell
python scripts/ops_db.py retention-plan backups
```

该命令只预览经过认证且已到期的备份，不按文件修改时间判断，也不执行删除。存在同名 `.hold` 标记的备份受到保护。

`destroy-encrypted` 默认仅预览，须指定一个备份、所属目录、预期 SHA-256 与原因。实际执行还需明确传入 `--yes` 和目录内的 `--receipt` 回执路径。工具核对文件与摘要、到期状态、保留标记及硬链接，防止误删已变化的目标；回执带有独立用途的 HMAC 认证，可用 `verify-receipt` 验证。认证通过仍须核对回执状态；中断状态需要人工核查，不能视为销毁完成。回执记录文件删除操作，不证明底层存储已完成物理擦除。

## 冻结报告导出

`scripts/export_audit_pdf.py` 从只读数据库导出已归档版本，先验证内容指纹，不重新计算规则或生成报告。PDF 尚未归档时会提示失败，可改用 `--format html` 导出冻结 HTML；已有输出文件不覆盖。运行者须具有读取该数据库的权限。

```powershell
python scripts/export_audit_pdf.py --list
python scripts/export_audit_pdf.py AUDIT_ID --version 1 --output output/saved.pdf
```

## 容器配置

`Dockerfile` 提供依赖、Chromium、中文字体与非 root 运行用户；`compose.yaml` 将服务端口绑定到宿主机回环地址，数据库使用独立卷。`.dockerignore` 排除 Git、环境密钥、本机依赖、数据库、备份和报告。

```powershell
docker compose config
docker compose build
docker compose up -d
```

这些文件是运行配置，本地 Python 回归不等于容器或生产环境验收。正式部署仍需配置 HTTPS、可信代理、`TAXPEARLS_COOKIE_SECURE=1`、持久化目录访问控制，并验证备份恢复与邮件链路。

## 邮件配置

配置 `TAXPEARLS_RESEND_API_KEY`、`TAXPEARLS_EMAIL_FROM_ADDRESS` 和 `TAXPEARLS_EMAIL_FROM_NAME`。发件地址须使用已在服务方验证的域名。`TAXPEARLS_PUBLIC_BASE_URL` 用于邮箱认证及密码重置链接，只接受可信源站，不带路径、查询、片段或用户信息；正式环境必须显式填写自己的 HTTPS 地址，同时配置 `TAXPEARLS_COOKIE_SECURE=1`。本机留空时仅允许 localhost、127.0.0.1 和 ::1 回退；外部请求缺少可信基址时拒绝申请，不使用客户端 Host 拼接链接。

邮箱验证码登录、邮件链接确认与密码重置均绑定发起浏览器；打开链接不会自动认证，凭证需明确确认且只能使用一次。重置成功后撤销已有会话；未知邮箱与已绑定邮箱的重置申请获得一致响应。外部环境须明确配置可信 HTTPS 基础地址，不能依赖请求 Host 生成邮件链接。接口回归使用模拟发件，真实送达须另行验证。需要实际发信时可手动运行 `scripts/send_test_email.py --to person@example.com`，应换成获准的真实收件地址。

须在发起申请的同一浏览器、同一站点完成确认；邮件内置浏览器与原浏览器不一致时，可回到原浏览器或重新申请。六位验证码和独立长令牌共用有效期，重发使旧凭证失效；成员停用或密码重置撤销待用凭证，恢复成员不会复活凭证。短期确认结果仅留在当前页面内存，刷新后需重新申请。

邀请和邮箱链接可能携带持有者凭证。代理、CDN、APM 和前端遥测须对凭证路径与敏感参数脱敏，不记录请求体中的验证码、令牌、密码或 Cookie。页面清除地址栏凭证及发送缓存/来源限制头不能替代外部日志配置。正式环境还须验证 HTTPS、邮件域名、真实送达和日志脱敏。

## 企业材料密钥与恢复

企业上传须配置 `TAXPEARLS_MATERIAL_KEY`：独立的 32 字节随机密钥，以 Base64 编码。服务从进程环境读取，Web 启动时也加载本机 `.env`；不要复用模型、邮件或备份密钥。未配置或密钥格式无效时拒绝上传，不自动生成密钥，也不降级明文存储。

原件字节、文件名、分析、修改与确认载荷认证加密保存，数据库备份包含这些密文及关联记录。恢复到独立服务时须同时注入原材料密钥，只有备份密钥不能解密企业材料；丢失材料密钥无法恢复原件内容。密钥不得与数据库或备份一起提交。

管理员明确删除原件前展示关联结果、重检和备份副本影响；已有确认快照及冻结报告保留，备份中的原件副本可能仍存在，不宣称介质彻底擦除。请求日志在重启后保留已提交、失败或未完成状态；响应未知时先查已有结果，不直接重复确认。

## 后续安全与部署验收

企业原件与材料版本载荷已使用独立密钥认证加密留存；其他业务敏感字段迁移和环境身份隔离仍待接入，现有命令不能代替这些未完成能力。

- 原件、敏感字段和备份分别确定密钥用途与管理范围；密钥通过受控配置注入，不写进文档、日志、命令行或版本控制。企业原件密钥与备份密钥分别保管，实际部署须验证权限、下载、备份恢复及删除影响。
- 敏感字段迁移须验证读取、写入、旧库转换与失败恢复；已实现的备份加密不等于业务字段已经加密。停服迁移前保护可验证的安全副本，恢复后检查机构归属与结果一致性。
- 演示、教学与生产分别确定数据、运行用途和实例身份，恢复前校验目标与格式；相同企业标识不能跨机构或环境授权访问。容器启动不等于已经完成生产隔离。
- 回滚须核对目标代码、数据结构与密钥格式的兼容关系；不能只切回应用版本而忽略数据升级。真实部署、密钥保管与物理环境隔离须单独验收。

## 通知邮件

`TAXPEARLS_NOTIFICATION_EMAIL_ENABLED=0` 为默认值。启用摘要邮件还须配置邮件密钥与已验证的发件地址，且接收人本人同意邮件订阅。队列保存摘要、幂等键及投递状态，服务重启后可继续处理；已被服务方受理的投递不重复发送，未知响应需按状态申请重试。站内通知不依赖邮件服务。

当前仅安装邮件投递适配器。多渠道队列、会话确认绑定、一次性身份流程与绑定撤销属于基础实现，外部 IM 或第三方身份提供方的公开接口、令牌验证与页面尚未接入；无需填写额外外部服务密钥。未配置邮件密钥不影响审计结果和站内通知保存。
