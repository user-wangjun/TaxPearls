# 税海拾珠 · 运行、备份与恢复

## 本机运行

使用 `python -m webapp --host 127.0.0.1 --port 8000` 启动，`/healthz` 用于存活检查。数据库由 `TAXPEARLS_DB` 指定，默认写入 `instance/taxpearls.db`。配置文件使用 `.env`，填写前从无密钥的 `.env.example` 复制。

Windows 使用本机 Chrome 导出 PDF；Linux 容器配置 `TAXPEARLS_PDF_BROWSER=chromium`。固定依赖见 `requirements.lock`。Web 材料草稿与任务状态保存在进程内存中，应使用单个应用进程。

## 备份、验证与恢复

使用 SQLite 在线备份 API 在内存中捕获已提交的 WAL 数据，再用 AES-256-GCM 认证加密生成 `.tpbackup` 文件；不生成中间明文备份。密钥 `TAXPEARLS_BACKUP_KEY` 必须是独立的 32 字节随机密钥的 Base64，并通过安全方式注入进程环境。运维脚本不自动加载 `.env`，也不接受命令行密钥；请将密钥与备份分开保管。

```powershell
python scripts/ops_db.py backup-encrypted --database instance/taxpearls.db --output backups/checkpoint.tpbackup --retention-days 30
python scripts/ops_db.py verify-encrypted backups/checkpoint.tpbackup
```

示例的 30 天仅是参数示范，实际保留期由业务与运维要求决定。校验会检查密钥、认证标签和数据库完整性，密钥错误或内容被修改时拒绝恢复。已有输出文件不会覆盖。

恢复会替换指定数据库。先停止应用服务，再执行；脚本检测 SQLite 日志和运维锁，先生成并验证现有数据库的加密安全副本，随后恢复。恢复期间若目标数据库发生变化则取消覆盖。

```powershell
python scripts/ops_db.py restore-encrypted backups/checkpoint.tpbackup --database instance/taxpearls.db --safety-retention-days 30 --yes
```

恢复返回安全副本位置；需要回退时仍须停服，以该 `.tpbackup` 副本为恢复输入。密钥、数据库、备份和回执均不纳入 Git。明文兼容命令 `backup` 和 `restore` 仅供迁移或测试，必须明确提供 `--allow-plaintext`；明文恢复还需 `--yes`。

## 保留期与销毁回执

```powershell
python scripts/ops_db.py retention-plan backups
```

该命令只预览经过认证且已到期的备份，不按文件修改时间判断，也不执行删除。存在同名 `.hold` 标记的备份受到保护。

`destroy-encrypted` 默认仅预览，须指定一个备份、所属目录、预期 SHA-256 与原因。实际执行还需明确传入 `--yes` 和目录内的 `--receipt` 回执路径。工具核对文件与摘要、到期状态、保留标记及硬链接，防止误删已变化的目标；回执带有认证签名，可用 `verify-receipt` 验证。中断状态需要人工核查，不能视为销毁完成。回执记录文件删除操作，不证明底层存储已完成物理擦除。

## 冻结报告导出

`scripts/export_audit_pdf.py` 从只读数据库导出已归档版本，先验证内容指纹，不重新计算规则或生成报告。PDF 尚未归档时会提示失败，可改用 `--format html` 导出冻结 HTML；已有输出文件不覆盖。运行者须具有读取该数据库的权限。

```powershell
python scripts/export_audit_pdf.py --list
python scripts/export_audit_pdf.py AUDIT_ID --version 1 --output output/saved.pdf
```

## 容器配置

`Dockerfile` 提供依赖、Chromium、中文字体与非 root 运行用户；`compose.yaml` 将服务端口绑定到宿主机回环地址，数据库使用独立卷。`.dockerignore` 排除 Git、环境密钥、本机依赖、数据库、备份和报告。

```powershell
docker compose config
docker compose build
docker compose up -d
```

这些文件是运行配置，本地 Python 回归不等于容器或生产环境验收。正式部署仍需配置 HTTPS、可信代理、`TAXPEARLS_COOKIE_SECURE=1`、持久化目录访问控制，并验证备份恢复与邮件链路。

## 邮件配置

配置 `TAXPEARLS_RESEND_API_KEY`、`TAXPEARLS_EMAIL_FROM_ADDRESS` 和 `TAXPEARLS_EMAIL_FROM_NAME`。发件地址须使用已在服务方验证的域名。`TAXPEARLS_PUBLIC_BASE_URL` 指向用户可访问的应用基础 URL，用于密码重置链接；正式环境必须使用自己的 HTTPS 地址。

邮箱验证码登录、邮件链接确认与密码重置均绑定发起浏览器；打开链接不会自动认证，凭证需明确确认且只能使用一次。重置成功后撤销已有会话；未知邮箱与已绑定邮箱的重置申请获得一致响应。外部环境须明确配置可信 HTTPS 基础地址，不能依赖请求 Host 生成邮件链接。接口回归使用模拟发件，真实送达须另行验证。需要实际发信时可手动运行 `scripts/send_test_email.py --to person@example.com`，应换成获准的真实收件地址。

## 仿真门户采集

```powershell
python scripts/rpa_sandbox.py --output output/rpa-sandbox.xlsx
```

该工具仅在本机启动纯合成财务与税务页面，通过浏览器采集后生成标准 Excel；不连接真实门户或使用真实账号。输出可用于解析与规则演示，不代表已接入生产财务软件或电子税务局。

## 通知邮件

`TAXPEARLS_NOTIFICATION_EMAIL_ENABLED=0` 为默认值。启用摘要邮件还须配置邮件密钥与已验证的发件地址，且接收人本人同意邮件订阅。队列保存摘要、幂等键及投递状态，服务重启后可继续处理；已被服务方受理的投递不重复发送，未知响应需按状态申请重试。站内通知不依赖邮件服务。
