# 税海拾珠 · TaxPearls

税海拾珠是面向财税核对与教学实训的本地 Web 应用。项目将企业材料转换为带来源的标准指标，使用确定性规则生成风险线索、计算过程和证据卡，并导出 HTML 与中文 A4 PDF 报告。

GitHub：[user-wangjun/TaxPearls](https://github.com/user-wangjun/TaxPearls)

平台支持 AI 材料提取、风险解读和总体叙述，配置模型服务并启用后使用。标准模板解析、确定性规则核对、证据展示和报告导出可独立运行。

## 核心流程

```text
登录 → 选择或建立客户 → 上传并留存原件 → 核对主体、期间与指标
     → 查看缺项与检查范围 → 确认材料版本 → 执行适用检查 → 保存审计与冻结报告
     → 补传或修正后重新分析、确认，保存新的结果版本
```

系统将规则结果分为“命中”“通过”和“未执行”。材料缺失、值无效或分母不可用时保持“未执行”，不会把缺数据误判为通过。

## 快速启动

需要 Python 与本机 Google Chrome。启动 Web 服务前，须通过本机 `.env` 或进程环境配置 `TAXPEARLS_FIELD_KEY`：独立的 32 字节随机密钥，以 Base64 编码。密钥应稳定保管，应用不自动生成或替换。已有数据库先按 [停服迁移步骤](docs/05-部署备份恢复与回滚.md#敏感字段加密与离线迁移)处理。

从项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m webapp --port 8016
```

打开 http://127.0.0.1:8016 。首次使用创建平台管理员，没有预置账号。默认只监听本机；停止服务按 `Ctrl+C`。

业务数据库默认位于 `instance/taxpearls.db`。`instance/` 已排除在版本控制之外。

### 命令行核对

标准 Excel 也可以通过命令行直接生成报告：

```powershell
.\.venv\Scripts\python.exe -X utf8 main.py -i "你的审计材料.xlsx"
```

可使用 `--rules` 指定规则目录、使用 `--output` 指定 PDF 输出位置。生成文件默认写入 `output/`，该目录不纳入版本控制。

## 功能模块

### 材料解析与业务勾稽

- 导入标准 Excel、数电发票 XML/明细、银行流水与调节底稿。
- 归集多期间利润表和资产负债表指标；发生额按期间累计，时点余额不跨期相加。
- 核对工资、社保等人力记录，缺项不猜测、重复记录不重复计数。
- 关联合同台账、履约记录、发票和资金流水，检查金额、期间与复核状态。
- 上传后先展示企业、所属期、指标值、来源及计算说明，再由用户确认执行。
- 输入分析核心按单企业、单主期间检查归属与可计算范围，反馈分为必须处理、缺失但可继续、建议补充；分析阶段不执行风险判定。
- 标准账表数值修正保留原值、单元格位置和用户值，再重新派生指标；不修改原件，不用零填补缺项。
- 提取记录包含来源、程序指纹、模型请求及提示/结构指纹，未知模型版本保持未知。单组分析、修正、确认与补传已接入公开接口和页面。
- 上传字节、文件名和材料版本使用独立密钥认证加密；下载及管理员删除复查当前权限并记录操作。删除前展示影响，备份中的副本可能仍存在。
- 确认绑定服务端分析与规则快照，同一分析版本的重复或并发确认复用已有结果；材料版本发生变化时仍需重新核对。补传保留手填修正，历史结果读取其当时确认材料。

### 规则、证据与报告

- 内置 24 条 YAML 条件规则，覆盖内部勾稽、外部交叉和指标偏离。
- 提供 96 个标注样例，覆盖命中、通过、阈值边界和缺项场景。
- 审计详情展示规则结论、严重程度、阈值、实测值、公式和来源证据。
- 规则管理支持启停、参数编辑、材料快照试跑和版本保存。
- 规则可设置生效区间；跨越不同规则版本的材料必须拆期核对。
- 关联方分析读取主体、持股或控制关系及关联交易，只使用已复核且有依据的路径。
- 报告支持机构名称、抬头、页脚和 Logo，输出 HTML 与中文 A4 PDF。
- 报告版本冻结保存 HTML、证据及规则快照，PDF 生成后按版本保存并校验；归档版本导出不重新计算。
- 工作台保留审计企业名称；客户档案名称不同时并列展示关联名称，不修改原审计或客户档案。
- 同一客户可比较跨期风险变化；机构总览汇总多个客户，报告包含水印和指纹验证入口。
- 模型生成的命中解读和总体叙述必须引用已有证据，不改变确定性规则结论。

### 客户、账号与权限

- 使用 Argon2id 保存密码，浏览器会话使用 HttpOnly Cookie。
- 提供平台管理员、机构管理员、会计、教师和学生角色。
- 机构数据相互隔离；会计只处理自己负责的客户。
- 支持客户建档、负责人分配、审计记录和操作日志。
- 默认使用邮箱和密码登录，同时支持用户名；验证码和邮件链接作为备用入口。
- 未勾选保持登录时会话有效期为 12 小时；勾选后为固定 30 天，Cookie 与服务端会话同步到期，不自动续期。退出撤销当前会话，重置密码撤销账号全部会话；密码不写入浏览器存储。
- 登录包含弱口令校验、失败限频和一次性密码重置；账号可以关联邮箱。
- 平台可创建机构邀请码，默认小型 5 席，可选中型 20 席或大型 50 席；总席位包含机构管理员。邮箱验证码、本机校验题、邀请码和名额消耗共同完成开户校验。
- 平台管理员管理机构席位与邀请；机构管理员在本机构配额内创建、停用和恢复成员。成员来源、邀请状态与配额变更可追查。
- 注册、验证码登录、邮件链接验证和密码重置使用限时、单次的浏览器绑定凭证；打开链接须明确确认，不会自动登录或消耗凭证。注册仍须有效邀请，角色与机构由后端确定。

### 通知与协作

- 审计完成和高风险条目可生成站内通知，支持订阅和已读状态。
- 机构管理员可设置站内通知接收范围，邮件开关只能由接收人本人控制。
- 摘要邮件默认关闭，只发送规则摘要，不附带原始财务材料。
- 邮件关闭或发件地址缺失时，仍保存审计结果和站内通知；通知处理失败不影响已保存的审计结果。
- 邮件队列使用稳定幂等键，并区分已受理、失败和结果未知状态，避免盲目重复发送。
- 通知投递支持按渠道保存摘要、幂等键和状态；渠道绑定基础要求当前登录会话确认。当前仅安装邮件投递适配器，外部 IM 服务、公开绑定入口与真实送达尚待接入。

### 教学与辅助工具

- 提供规则知识网络、按规则生成的仿真账套，以及班级、组卷、作业发布、提交与评分。
- 支持练习评分、漏检与误报说明，以及操作时的沙箱反馈。
- 班级学情按当前有效名册和最新提交统计；未交、损坏和未执行分别列示，人工调分不改变客观正确率。
- 个人画像与训练档案按授权范围展示跨作业薄弱项；同刻记录合并，口径改变或数据缺损时不连接趋势线。
- 新正式提交与错题记录同事务保存；已有提交须明确同步，独立重练保存订正状态，不改原成绩、教师批改或学情画像。
- 教师只能将明确标记的仿真材料用于教学流程。
- 学生通过发布的作业进入练习，正式企业材料不会作为教学样例。
- 本机仿真门户可以生成标准 Excel，用于解析、核对和演示，不连接真实业务门户。

多源材料支持范围以 [输入输出约定](docs/01-输入输出与业务逻辑.md) 为准，不保证任意财务软件导出格式都能直接识别。模型提取与问答按配置启用，调用前须确认材料发送范围。

## 配置

按需将 `.env.example` 复制为 `.env`，填写前先确认目标文件不存在。进程环境变量优先于 `.env`。

| 配置组 | 主要变量 | 默认行为 |
| --- | --- | --- |
| 服务与数据 | `TAXPEARLS_HOST`、`TAXPEARLS_PORT`、`TAXPEARLS_DB` | 监听本机，数据库写入 `instance/` |
| 部署身份 | `TAXPEARLS_ENVIRONMENT`、`TAXPEARLS_INSTANCE_ID` | 本机默认 local；培训与生产须显式使用各自独立实例 ID，错误身份拒绝访问 |
| 容器配置 | `TAXPEARLS_ENV_FILE`、`TAXPEARLS_IMAGE_TAG`、`TAXPEARLS_BIND_PORT` | Compose 要求外置配置、明确版本标签与回环端口；项目、卷和网络按实例命名 |
| PDF | `TAXPEARLS_PDF_BROWSER` | Windows 使用 Chrome，Linux 或容器使用 Chromium |
| 外部模型 | `TAXPEARLS_AI_ENABLED`、`TAXPEARLS_AI_API_KEY`、`TAXPEARLS_AI_BACKUP_API_KEYS`、`TAXPEARLS_AI_BASE_URL` | 默认关闭，不发送材料 |
| Resend 邮件 | `TAXPEARLS_RESEND_API_KEY`、`TAXPEARLS_EMAIL_FROM_ADDRESS` | 未配置时不发送邮件 |
| 审计摘要邮件 | `TAXPEARLS_NOTIFICATION_EMAIL_ENABLED` | 默认关闭，仍保留站内通知 |
| 企业材料 | `TAXPEARLS_MATERIAL_KEY` | 独立 32 字节随机密钥的 Base64；未配置时拒绝企业上传，不降级为明文留存 |
| 敏感证据 | `TAXPEARLS_FIELD_KEY` | Web 启动必需；须与材料及备份密钥独立，缺失或不匹配时拒绝读写 |
| 加密备份 | `TAXPEARLS_BACKUP_KEY` | 运维脚本从进程环境读取独立密钥，未配置时拒绝加密操作 |
| 邮件链接 | `TAXPEARLS_PUBLIC_BASE_URL` | 本机允许回环 HTTP，外部环境须显式配置可信 HTTPS 地址 |
| 外部访问 | `TAXPEARLS_COOKIE_SECURE`、`TAXPEARLS_TRUSTED_PROXY_IPS` | 本机 HTTP 配置；部署时按实际代理和 HTTPS 调整 |

`.env`、密钥、证书、数据库、备份、上传材料、日志和浏览器检查状态均不进入 Git。邮件发件地址必须已在 Resend 中验证；接口测试使用本地模拟服务，不代表真实邮件送达。

### 模型备用密钥

可在服务端配置 `TAXPEARLS_AI_BACKUP_API_KEYS`，使用英文逗号分隔，填写后重启服务。主用与备用去重后最多 10 把，空项忽略；密钥只留在受控 `.env` 或进程环境中。材料提取、知识网络问答、命中解读和总体叙述使用同一服务地址、模型及能力设置。

按主用到备用顺序尝试，仅 HTTP 401 或 402 才切换下一把；配置备用列表时，失败密钥在同一进程内跳过五分钟，重启清空该状态。超时、限流、服务器故障、参数错误、重定向和无效响应不触发切换，所有尝试共用本次请求的剩余超时预算。全部不可用时明确报错，日志只记录序号和 HTTP 状态，不记录密钥、材料或上游错误正文。没有备用配置时保持单密钥请求行为。

提取请求数和溯源调用数仍按逻辑请求计数，每次逻辑请求最多尝试列表中的每把密钥一次。同账号的多个密钥若共享余额，切换不能解决账号余额耗尽。此功能使用本机模拟服务验证，真实提供方错误码和可用性仍须单独确认。

## 样例与验证

`samples/样例企业-审计材料.xlsx` 与 `samples/合成测试数据/` 均为仿真材料。`samples/规则核对样例.yaml` 提供 96 个标注样例。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -B -X utf8 scripts/check_project.py
.\.venv\Scripts\python.exe scripts/check_rules.py
```

统一检查入口执行 Python 语法、依赖一致性、Ruff、前端语法与交互回归，以及完整单元测试。它使用临时数据库，关闭外部 AI 和邮件发送，并比较检查前后的源码指纹；检查失败或源码发生变化时返回非零退出码。

GitHub Actions 在推送和 PR 时使用同一入口检查，安装 Chromium 和中文字体以验证 PDF 导出。CI 配置不包含部署或发布步骤。规则测试、接口测试和本机浏览器检查不能代替真实邮件、生产部署或真实企业材料验收。

当前整合版本的 649 项本地隔离回归通过，覆盖企业、平台和教学流程、材料并发确认与版本冲突、字段加密、部署身份、恢复及备用密钥切换；依赖、语法、Ruff、两组前端交互检查通过，源码指纹保持一致。仿真浏览器验证覆盖学生错题独立重练、正式成绩与证据保持不变、教师学情与画像、退出后清空数据及桌面/390px 页面。GitHub Actions 随推送复核，真实模型、邮件、课堂、容器与生产环境另行验收。
