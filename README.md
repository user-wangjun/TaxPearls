## 启动

已建立独立的 `.venv`。从本目录运行：

```powershell
.\.venv\Scripts\python.exe -m webapp --port 8016
```

打开 http://127.0.0.1:8016 。首次启动创建平台管理员，没有预置账号。按 `Ctrl+C` 停止；端口被占用时改用 `--port 8017`。

重新建立环境时：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
Copy-Item .env.example .env
```

复制配置仅在没有 `.env` 时执行，避免覆盖已经填写的配置。AI 默认关闭，本地解析、规则计算与报告不依赖外部模型。密钥是否已配置以本机 `.env` 为准，不在文档中展示；启用模型或邮件前核对相应配置与开关。本次验收未调用真实模型或发送真实邮件。

## 实现范围

- Python CLI：标准 Excel → 带来源的指标 → 确定性 YAML 规则 → HTML/A4 PDF。
- FastAPI 工作台：材料核对、审计证据、历史、客户、仪表盘、规则管理和机构报告品牌。
- 24 条规则、96 个标注样例；缺失、无效或零分母数据保持“未执行”。
- 多期间序列、数电发票 XML/Excel、银行流水与逐笔调节、人力记录、合同/履约/四流勾稽、多客户材料分组。
- SQLite 快照、Argon2id 登录、角色/机构/客户权限、实训提交和评分、审计日志、登录限制、邮箱绑定和密码重置接口。
- 模型提取、知识网络问答、命中解读和总体叙述的协议、证据引用校验与缓存实现。
- 本机合成 RPA 门户采集、数据库备份/校验/恢复、Docker/Compose 配置。

在原远程重建基线上，另行接回旧本地的工程增量：

- 创始码邀请、邮箱验证及机构管理员注册；机构成员邀请和完整自助开户仍未全部实现。
- 独立关联方图规则 G-001，包含主体、关系、交易证据路径及历史快照；普通材料缺少图数据时该项显示未执行。
- 按审计所属期间选择规则版本，保存完整规则快照，拒绝跨版本区间混用。
- 站内通知、订阅与摘要邮件队列；邮件需环境开关和本人同意，默认不发信。
- 跨期风险比较：自动选最近更早同粒度期间及其最新审计，也可手动选择旧快照；区分新增、消失、偏离恶化/改善、未执行和规则口径变化，不把缺材料/停用视为风险消失。
- 报告归档：历史检索/筛选/分页、不可覆盖的 HTML 版本与追溯清单；PDF 首次导出后冻结原文件。品牌/模板/叙述变化创建新版本，显式版本读取不重跑规则、不套用当前模板；校验和不等于防伪签名。

- 机构级多客户风险总览：按最新业务期间或指定期间，每户选一份冻结审计；区分命中、缺材料与无审计，按规则版本/定义分别统计，生成独立冻结的机构 HTML/PDF。仅本机构管理员可读，不是财务合并报表。
- 报告水印与原件核验：客户名与报告日期水印、逐页追溯标识；登录后按当前机构/客户权限核对冻结 HTML/PDF 的 SHA-256。文件在浏览器本机计算指纹，不上传报告内容；标识可复制，不是第三方数字签名或防转发保证。旧归档不改写，CLI 本地导出明确未登记服务器原件。
- 规则反向生成教学材料：从本期已启用规则读取输入和阈值，生成纯仿真账套及完整联动答案；教师核对后发布，学生查账/提交/评分。双方按权限下载不含答案的标准 Excel，重导入逐项核对数值，历史记录不套用新规则。
- 沙箱即时教学反馈：风险标注后定位原始证据，按单位和明确来源期间进行差额/比例试算；缺项、零分母、单位混用和错误跨期即时提示。不提前判断答案正确性、不保存草稿或改变正式评分。
- 班级/作业管理：教师通过界面管理班级名册、按顺序和分值组卷（1–30 份仿真案例）、保存草稿与统一发布/撤回、调整截止。学生查看逐题进度和加权评分；截止时间按本机时区输入、统一存 UTC，提交事务内复核成员/发布/时间，旧单案例作业兼容。

注册、图规则、版本区间和通知增量已作为第 18 条提交接入，前 17 条清理后的历史保持不变。跨期比较、报告归档、机构总览、水印核验、仿真出题、沙箱即时提示和班级/组卷管理是其后的工作区增量，尚未提交。详见 [TODO](TODO.md)。
