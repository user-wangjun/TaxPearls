# 税海拾珠 · TaxPearls

税务风险核对与教学实训项目。Web 工作台提供工作台、材料上传与核对、24 条确定性规则、可溯源证据卡，以及 HTML / A4 PDF 报告。

## 启动

需要 Python 与本机 Google Chrome。从项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m webapp --port 8016
```

打开 http://127.0.0.1:8016 。首次使用创建平台管理员，没有预置账号。默认只监听本机；停止服务按 `Ctrl+C`。

AI 默认关闭，标准模板解析、规则核对与报告导出不依赖外部模型。可按需将 `.env.example` 复制为 `.env` 并填写配置，复制前确认目标文件尚不存在。业务数据库默认位于 `instance/`，不纳入版本控制。

## 当前功能

- 工作台：按企业与期间查看经营指标、风险分布和审计记录。
- 上传材料：导入标准 Excel、数电发票 XML、银行流水与调节表，核对企业、期间和指标来源，再执行规则。
- 业务勾稽：多期间指标归集、人力记录、合同台账、履约记录及合同/发票/资金/履约四流核对；指标保留来源与计算口径。
- 规则核对：24 条 YAML 条件规则，覆盖内部勾稽、外部交叉和指标偏离；缺项或无效分母显示未执行。管理界面支持参数编辑、材料快照试跑与新版本保存，正式变更仅影响后续审计。
- 审计详情：命中、通过、未执行清单及证据卡，保留数值、来源、计算过程和阈值。
- 报告导出：机构可配置 Logo、抬头与页脚；HTML / 中文 A4 PDF 包含总体叙述与规则证据。叙述按证据指纹缓存，外部模型关闭时提示未配置，确定性统计和逐条证据仍可查看。
- 基础管理：Argon2id 登录、角色与客户归属、会话、业务记录与操作日志；审计结果持久化保存。
- 辅助界面：规则知识网络与基础仿真实训、作业提交和评分。

多源材料支持范围以 [输入输出约定](docs/01-输入输出与业务逻辑.md) 为准，不保证任意财务软件导出格式都能直接识别。模型提取与问答按配置启用，调用前须确认材料发送范围。

## 样例与验证

`samples/样例企业-审计材料.xlsx` 与 `samples/合成测试数据/` 均为仿真材料。`samples/规则核对样例.yaml` 提供 96 个标注样例。

```powershell
.\.venv\Scripts\python.exe scripts/check_rules.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

回归检查应使用独立测试数据库，可通过 `TAXPEARLS_DB` 指定路径。生成报告属于运行产物，不提交到仓库。

## 项目文件

- `webapp/`：Web 服务、页面、工作台样式与业务存储。
- `src/`：解析、指标、规则、报告和基础实训逻辑。
- `rules/`、`samples/`：规则及仿真样例。
- `templates/`：报告模板。
- `tests/`、`scripts/`：回归测试与规则核验工具。
- `docs/`：功能需求、输入输出和规则口径。

## 后续范围

企业原件加密留存、持久化材料确认与补传重检、规则生效区间、报告归档版本、机构成员邀请、通知、班级组卷与学情分析、字段加密、备份恢复及部署验收。

当前版本用于本地开发和仿真演示。行业参数为示意值，风险线索须人工复核；报告不能替代税务机关认定、税务鉴证或法律意见。真实业务上线还须完成敏感信息保护与部署验证。
