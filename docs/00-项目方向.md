# 税海拾珠 · 项目方向

TaxPearls 面向财税教学与机构账务检查，提供可解释的税务风险核对能力。每项结论应包含原始数值、取数来源、计算过程、阈值、依据和建议，供使用者复核。

## 当前范围

Web MVP 提供现有工作台布局、真实登录、标准材料导入与核对、24 条 YAML 规则、证据卡与 HTML / A4 PDF 报告；数据库保存审计结果和访问记录。

## 产品场景

| 场景 | 目标 |
| --- | --- |
| 财税教学 | 使用仿真材料开展查账、风险标注、证据复核与评分 |
| 机构账务检查 | 核对企业账表和申报材料，输出可追溯的风险线索 |

## 技术路线

- 识别层采用确定性规则，保留证据和计算口径。
- 报告由模板渲染为 HTML，再通过浏览器打印为 PDF。
- 模型提取、解读和问答作为后续辅助能力，输出须能引用材料与已计算结果。
- 关联方分析采用独立图规则；教学出题与评分引用固定规则和答案。

## 后续能力

企业材料留存与确认重检、规则与报告版本管理、机构成员邀请、班级组卷与学情分析、关联方分析、通知、安全加密与部署运维。

## 数据与使用边界

开发与教学演示使用仿真材料。真实业务接入须先完成权限、加密、审计留痕及备份恢复等保护。规则和行业参考值应保留出处与适用范围，不承诺未经验证的准确率。
