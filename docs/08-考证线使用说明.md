# 08 - 考证刷题线使用说明（教师端 / 学生端）

> 适用版本：main 分支（2026-10 交付基线）。目标用户：高校教师（管理员）与学生。
> 部署与备份见 05 号文档；需求背景见 07 号文档（TP-CERT-001）。

## 一、启动系统

1. 双击 `instance\启动教师系统.bat`（黑窗口即服务器，**保持开着**，关闭 = 停止服务）。
2. 教师页：`http://127.0.0.1:8000/training-staff`
3. 学生页：`http://127.0.0.1:8000/training-certificates`
4. 首个教师账号由部署时创建（初始示例：staff01）。**首次登录后请立即点右上角「改密码」**。

## 二、教师端操作指南（training-staff）

登录后自上而下依次是：

### 1. 证书与考试日期
- 「＋ 新建证书」：编码（如 cjkj）、名称、科目清单（逗号分隔）。
- 「考试日期 → ＋ 录入日期」：类型选「官方考试日」（有官方公告时）或「预计考试日」；学生倒计时**官方日期优先**，没有官方日期时用学生个人计划日兜底。日期被学生目标引用时删除会被拒绝。

### 2. 内容版本（题源治理）
- 同一证书仅一个启用版本；发布新版本自动退役旧版本；旧作答仍按当时版本回溯。
- 当前仅开放「仿真题」题源；真题/回忆题/模拟题须获授权后启用，生成题不冒充真题。

### 3. 考纲知识点
- 树状结构（编码/名称/科目/上级）。「⇪ 批量导入」支持清单 Markdown 或 CSV，按编码幂等导入（已存在只更新非空字段）。
- 每个知识点卡片下有三个入口：
  - **＋ 规则**：挂接风险规则（学生刷题的题目来源）；
  - **＋ 标注**：三类标注（考证高频 / 企业风险 / 学生易错），「考证高频」必填依据与依据版本；
  - **＋ 关系**：前置知识 / 概念关联 / 易混淆（用于图谱与学习路径）。
- 「内容运营统计」卡片按证书 × 依据版本汇总标注与题目关联覆盖情况。

### 4. 学生管理（本交付新增）
- **＋ 添加学生**：院校（必填）、学号、姓名、班级选填；初始密码留空 = `Tp#学号2026`。
- **⇪ 批量导入**：粘贴名单，每行 `学号,姓名,班级`（逗号或中文逗号，空行忽略），设置统一初始密码（≥8 位）与默认班级。重复学号自动跳过并在结果里说明原因。
- **重置密码**：立即清除该学生全部登录会话（踢下线），把新密码线下告知学生。
- **停用/启用**：停用立即拒绝登录；启用即恢复。学生记录不物理删除（作答历史与档案保留）。
- 学生登录入口在学生页，用「学号 + 密码」（多院校存在同学号时需再填院校名）。

### 5. 密码与账号安全
- 头部「改密码」：验证当前密码，新密码 ≥8 位且不得与旧密码相同；成功后**所有会话失效**（含当前页），需重新登录。
- 忘记密码：由其他管理员重置；单管理员部署时需在库内重置（见 05 号文档）。

## 三、学生端操作指南（training-certificates）

1. **登录**：学号 + 密码（初始密码由教师发放；首次登录后请点右上角「修改密码」自助改为私密密码）。
2. **选证书、设目标**：在证书目录选择「初级会计职称」，设定考试日期（可选官方日期或个人计划日）。首页即显示**倒计时**（按中国日历日，永不为负）。
3. **自主练习**：选择知识点 → 系统按该知识点挂接的规则生成仿真题（确定性种子，可重做同题）→ 作答 → 提交判分 → **解析在判分后开放**。
4. **错题重练**：错题本支持「原题重做（同种子）」或「再练新题」；覆盖统计显示知识点的练习覆盖与掌握程度。
5. **笔记与提问**：每个知识点可写个人笔记（可删除）；有疑问可发起 AI 答疑——AI 只解释思路，**不改判分数、不代替教师维护内容**。
6. **学习档案**：按知识点聚合个人作答、错题、笔记与提问记录；掌握程度四级口径，一次重练答对不代表长期掌握。
7. **修改密码 / 退出登录**：右上角「修改密码」验证当前密码，新密码 ≥8 位且不得与旧密码相同，成功后**所有会话失效**需重新登录；「退出登录」立即失效当前会话。

## 四、边界与合规要点（务必知悉）

- 知识点内容依据 **2026 年度全国会计考办大纲**人工整理；机构资料与 AI 生成考纲不作依据。
- 题目当前为**规则仿真题**，页面明确标识，不冒充真题；真题须经授权（授权文号入 source_ref 并经管理员审核）。
- AI 答疑不改判、不代写内容；个人易错数据仅本人可见，不反向写入公共标注。
- 2027 年官方考务公告发布后（预计 2026 年 12 月上中旬），教师应在「考试日期」录入官方日期；2027 版大纲发布后升内容版本。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 登录提示「用户名或密码不正确」 | 确认服务用 bat 启动（连主库）；检查大小写/全角符号；密码遗忘走重置 |
| 浏览器 Failed to fetch | 服务未启动或黑窗口被关；重新双击 bat |
| 批量导入某行被跳过 | 看结果明细：多为重复学号或格式缺姓名 |
| 学生说「突然被退出」 | 教师重置过密码或停用账号，与学生确认 |
| 倒计时显示过期 | 官方日期已过仅作标记，不会自动改学生目标状态 |
